# 群成员记忆格式与更新

## 保存位置

`knowledge/group-memory/<account_id>/<group_id>/` 为一个账号在一个群内的记忆分区。成员文件放在 `members/`，互动文件放在 `interactions/`。文档规范由维护工具读取；聊天检索只返回当前分区内与话题有关的实际记录。

## 成员文件

文件名为成员 QQ 号，例如 `123456789.md`。文件头保存 `id`、`account_id`、`group_id`、`qq_number`、`display_name`、`updated`。`qq_number` 使用字符串保存，来源为接收事件中的发送者 QQ 号。正文按称呼、公开自述、兴趣、交流偏好和明确托付的事项组织，仅写有内容的章节。

已确认的成员类型可在文件头增加 `participant_type: ai` 或 `human`，并用 `source` 标记确认来源；未记录时保持未知。离线话题判断仅投影当前群可见发言者的类型与来源，正文继续保存具体依据。

每条记录包含：

| 字段 | 内容 |
|---|---|
| record_id | 稳定记录编号 |
| summary | 正向、具体、简短的内容描述 |
| basis | 本人自述、他人提及或观察事实 |
| evidence | 来源消息编号、发言者、时间及支持结论的最小摘录 |
| updated | 最近核实或更新的时间 |
| valid_until | 有明确期限时填写 |

## 互动文件

文件头保存 `id`、`account_id`、`group_id`、`participants`、`updated`。`participants` 保存参与成员的 QQ 号字符串列表；证据中的发言者同样使用 QQ 号。正文保存具体互动摘要与证据，字段沿用成员记录。关系有明确依据时填写 `relationship`；证据仅支持具体互动时，此字段留空。

## 记录与更新

- 正文直接描述已发生的互动、明确自述及交流偏好，使用中性、具体的语言。
- 本人陈述、他人提及和观察事实分别标注依据；归因保持与原话一致。
- 新信息指向同一事项时更新原条目；来源冲突时保留归因和日期，等待核实。
- 兴趣与偏好随新的明确表达更新；有期限的事项到期后退出日常检索。
- 成员提出纠正、删除或停止记录要求时，按指定范围执行。
- 记录围绕群内交流所需的公开信息；证据采用支持条目的最小摘录。
- 规范与工具操作规则保存在本文件，成员及互动正文只保存实际信息。
