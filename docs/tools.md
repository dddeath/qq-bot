# 资料与视频工具

## 文字资料

B站 MCP 提供搜索、视频信息、分 P 字幕、章节、动态、评论、楼中楼和弹幕。`get_video_context` 汇总各来源，保留各自状态与缺失说明。评论上限为 1–50，默认 10；弹幕上限为 1–200，默认 80。字幕和弹幕绑定选定分 P。

## 视频四工具

| 工具 | 输入与结果 |
|---|---|
| `watch_video(video)` | 准备视频并返回时长 |
| `sample_video_frames(video, …)` | 生成全片或指定时间段的概览，返回 `sample_id` |
| `get_frames(sample_id, kind, start, count)` | 读取已有拼图或图片；`start` 为从 1 开始的图片序号，`count` 最多 3 |
| `get_frame_at(video, time)` | 按秒数、`mm:ss` 或 `h:mm:ss` 获取指定时刻图片 |

概览默认最多 18 帧、90 秒超时，实际限制由配置决定并出现在工具描述中。片段起止时间是视频绝对秒。先用全片概览定位，再按问题细化片段或补读时刻；所有补读沿用任务总预算。

## 角色工具

图库、图片理解、自身资料修改、互动及群文件权限分别由对应工具与账号绑定验证。图库归机器人所有，同一机器人的不同群共享素材，群发送仍检查当前授权。
