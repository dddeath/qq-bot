# 任务分类标签

工程技能使用以下五种角色；本仓库沿用同名标签，在普通任务文件的 `Status:` 行记录。

| 技能角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估和分类 |
| `needs-info` | `needs-info` | 待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可交给 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 本项目约定：主控检阅、全部检查与验收通过、待决策事项解决后，表示已完成关闭；同时设置 `Completion: complete` |

技能要求应用某个分类角色时，使用表中对应的标签。
