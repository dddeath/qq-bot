# 机器人与学习任务引用统一会话，工具配置按版本共享

## 背景

白龙娘、噗伊使用不同执行器；每日学习按批次创建原生线程，并为聊天提供资料。将所有会话挂在机器人下会使共享学习依赖某个聊天账号；逐机器人复制工具配置则会产生配置差异。

## 决策

- Bot 管理平台身份、人格引用、工具配置引用和聊天绑定。
- LearningJob 与 Bot 并列，管理来源、范围、调度及会话引用。
- Session 统一管理 chat、learning、research 用途，harness 为属性。学习和研究会话无需填写 QQ 身份。
- Run 保留每次执行实际产生的原生线程、状态、耗时与证据。每日学习的新线程归属相应批次，不将多个批次伪装成一个连续原生线程。
- ToolProfile 独立版本化。新机器人继承配置档引用，重新绑定自身账号、群、凭据目录与证据目录；人格不随工具继承。
- 机器人引用固定配置版本。修改配置档产生新版本，已运行实例继续使用已有版本，直至明确应用。
- 源账号专属的工具连接保留绑定范围；未完成接收方适配的工具记录待适配，不暴露原账号操作入口。

## 迁移

已有运行器和每日学习调度保持，统一管理层登记其配置引用并读取原执行记录。配置绑定使用独立存储，迁移或回滚不覆盖并发产生的消息和执行记录。控制接口仅供主控使用。

## 影响

不同机器人可共享工具定义与领域知识，同时保留群资料边界。跨执行器继承仍需适配原生能力及账号专属工具；配置导出、工具发现、真实调用和群内验收分别记录状态。
