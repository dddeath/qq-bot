# 按查询需求裁决，复用统一检索任务

同一回应的信息查询和表达查询可以具有不同收益，任务级单次开关会让两者共享同一执行结果。改为由现有知识应用任务保存各查询需求的首次裁决：宿主按查询采样，不再额外对整个任务采样。措辞改写、重试和异步续接复用原结果；查询内部的词法、向量和图谱通道维持现有行为。

Bot固定配置定义裁决策略，Session和Run记录实际配置。所有查询共享原任务预算，概率参数留在宿主审计，不进入模型提示词。现有任务与回执存储继续承担生命周期，不新建并行检索入口。旧协议任务保持旧语义，不把历史任务级结果补猜成查询级数据。

学习评审可读取查询贡献和原回复反馈，但当前阶段只记录建议；自动调整参数和线上应用各有独立验收关口。
