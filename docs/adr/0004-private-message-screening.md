# 原文隔离的预交付筛选

Bot保存激活、合批、筛选和主线程上下文策略。Session增加screening用途，按Bot与群隔离。筛选Run记录输入范围、模型、耗时、证据与判断；运行水位不写入Bot配置版本。

Luna low Fast仅作唤醒决策。输入使用本批消息、近期原始对话和相关群友画像。JSON只留在追踪层；主线程沿用Tulpa原始输入，自行判断回应。消息筛选水位与主线程交付水位分离。

阈值10，机器人权重0.25；活跃态10条或30秒合批。实际@和引用立即交付，后台任务与控制事件独立唤醒。主线程256k并关闭Fast。休眠压缩暂缓。

与0002的关系：话题维护仍只负责发送前新鲜度；筛选器是独立用途，不把话题维护结果改成回应队列或主线程提示。
