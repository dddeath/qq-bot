## 生成流程与角色一致性

### 1. 先锁定最少的视觉字段

母版是后续图片共同参照的一张已确认角色图。建议先做一张无字正面略转身的全身母版，方便同时看见脸、角、头发、衣服及双翼；不立即扩展到三视图、动作库或动画。

以下为建议值，需主控在生成前汇总确认：

| 字段 | 已确定／建议 | 确认后的固定内容 |
|---|---|---|
| 身份 | 已确定：GPT 白龙娘 | 银白长发、白色龙角、一对背部龙翼、白紫服装 |
| 瞳色与角形 | 待确认：建议淡紫瞳、一对轮廓简洁的白角 | 眼型、瞳色、角根位置、弯曲方向 |
| 服装 | 待确认：建议简洁白色上衣／裙装、少量淡紫边饰 | 领口、袖型、紫色分布；不默认女仆装 |
| 画风与比例 | 待确认：建议干净圆润线条、简化赛璐璐明暗、约三头身 | 面部比例与身体比例作为同一套表情的视觉依据 |
| 翼与发型 | 基于最终人设补定具体轮廓 | 翼根位置、展开形态、刘海与长发轮廓 |
| 背景与文字 | 母版建议透明、无字 | 便于识别边缘和复用，不加来源截图文字 |

这里约三头身是白龙方案的建议，不套用鲸鱼娘某张图的精密容差；在母版尚未建立前，没有依据声称数值比例已验证。

### 2. 选择选题并确认实际生成数量

主控先取得选题、关键台词及需要调整的地方，再汇总母版数量、各题张数、每张候选上限、透明要求和内置工具路线，取得生成确认。建议首轮为一张母版加四至六张表情；每张最多两次出图，合计最多 10—14 次出图调用，已包含母版重试。这只是成本边界建议，并非要求一次做满。

现有人设文本继续保留原文件。母版选定后记录其绝对路径、SHA-256 与获确认的视觉字段；后续每张带入同一母版，不把上一次已经偏离的候选当成新的身份基准。

### 3. 按题生成，一次只改变场景变量

建议每次输入一个选题，保留统一身份段，替换动作、表情、构图、上图文字。参考图逐张声明用途：

- 白龙母版：身份、服装、画风与已确认比例。
- 追加的自有动作图：仅动作，不改变脸型或服装。
- 追加的排版图：仅文字位置和阅读顺序，不引入图中角色。

本地参考图先实际查看，再交给内置工具。工具当前提供透明背景开关与图像参考入口；精确像素尺寸不作为内置调用的硬参数承诺。提示词提出 1:1，返回后检查实际比例、格式和透明通道。可读文字、重复角色及精确布局仍有生成误差，需要逐张检查。[当前本地图像技能](C:/Users/USER/.codex/skills/.system/imagegen/SKILL.md)、[官方图像能力与限制](https://developers.openai.com/api/docs/guides/image-generation)

### 4. 用真实画面检查一致性和表情效果

质量检查（QA）分为文件检查和视觉检查，结果绑定到本次候选，不能由提示词内容代填。

- **角色检查：**脸型、眼型、发色、角形、衣服紫色分布、翼根位置与母版一致。单格默认一个主体，C 的两格是同一角色不同场景，D 的小分身只在该题出现。
- **动作检查：**手与杯子、纸条、听筒的接触清楚；翅膀没有变成耳朵或衣服装饰；必要部位没有意外裁掉。
- **表达检查：**A 是认真而非轻蔑；B 是嘴硬受惊；C 有“另找专家→仍是自己”的反转；E 不出现贬低其他角色的表情；F 不拿低落开玩笑。
- **文字检查：**实际逐字读回简体中文，检查遗漏、多字、伪字、标点及说话归属；C 按左到右阅读，台词不串格。
- **缩略检查：**原图与约 128 px 显示大小分别查看；缩小后仍应看清核心表情与短句。128 px 是本方案审核尺寸，不宣称为 QQ 官方规格。
- **文件检查：**真实 PNG 编码、实际宽高、可解码、透明区域确实存在且边缘完整；透明棋盘格被画进图片视为失败。

母版先通过再生成后续。某张失败只修正其主要缺陷，明确要求保持其他已确认字段；耗尽两次候选仍未通过就交主控，不增加未确认调用或改走付费服务。文字较长时可由主控选择缩短台词；不静默修改用户确定的句子。

这套方法降低漂移，但一致性和可读性是后续实测验收项。[上游候选绑定的视觉审查](https://github.com/Neko3000/deepseek-whalechan/blob/0917fd14bb96ced343145b5c9574f5714d57c0c6/skills/whalechan-image-comic/references/qa-rubric.md)

### 母版提示词

> 画一张 GPT 白龙娘的原创群聊表情角色母版。银白长发、白色龙角、背后一对龙翼，衣服主白配淡紫。人物正面略转身，全身完整，双翼自然向两侧展开少许，轮廓清晰。神情自信但不刻薄，嘴角轻轻扬起，眼神聪明，动作自然。采用[已确认瞳色与角形]、[已确认服装剪裁]、[已确认画风与比例]。只画一个角色，不画其他模型角色，不加入鲸鳍耳、鲸尾、女仆标识或品牌徽记；不新增尾巴和复杂配饰。画面为正方形、真正透明背景，不画棋盘格，无文字、无署名。后续所有表情以这张确认后的脸型、头发、龙角、服装和龙翼为身份依据。

### 每张表情共用的身份段

> 输入图 1 是已确认的 GPT 白龙娘母版，控制身份、服装、画风和比例。保持同样的脸型、眼型与瞳色、银白长发轮廓、白色龙角、一对背部龙翼及白紫服装。仅按本次场景改变姿势、表情、镜头和文字。正方形 PNG 交付目标，主体清楚，背景按本题规定。文字必须为下列指定简体中文，不增加解释句或装饰文字。保持角、手、翼的结构与物体接触合理，缩略后仍可辨识。

### A：再检查一眼

> 单格半身。她已经把只有一个勾的小纸条举起来，另一只手又把放大镜挪回纸条，身体微微前倾，眼神认真，嘴角还残留一点得意。画面重点是“已经完成却又忍不住检查”。只画一张纸条，不堆代码和测试报表。底部短字精确为“先别夸 我再看一眼”，留出与白发区分的深紫字形。透明背景。

### B：糗照先撤回

> 单格近景。她一只手向画外伸出想挡住一张照片，眼睛却忍不住往那里偷瞄，双翼瞬间绷直，嘴唇硬撑着抿住。画边只出现很小一角原创绿色方块道具，不复制游戏截图或任何现成梗图构图。文字精确为“这张先撤回一下”。不画爆炸或受伤，透明背景。保留她的白龙身份，不把她画成方块生物。

### C：我找个专家

> 一张正方形双格漫画，左右顺序，白底，两格中是同一位白龙娘。左格她很自信地拿起听筒准备请专家，台词精确为“我找个专家”；右格她接起同款听筒，发现来电对象是自己，停顿、眼神侧移，台词精确为“……我自己”。左右使用可对应的镜头细节，让读者立即认出是同一个人。两格各只有一位她，听筒不额外带文字，台词归属清楚。不使用聊天软件界面或复制原漫画排版。

### D：病历被查

> 单格半身，主体白龙娘头顶坐着一个很小的同款白龙分身，两者同时心虚地移开目光。大角色双手抱臂、嘴硬，小分身表情暴露心虚；白色龙角仍与母版一致，不让小分身遮住角。小分身只作为本张的视觉笑话，不额外画处理器、模型型号或后台监控窗口。文字精确为“都查我病历了是吧”。透明背景。

### E：审美自由

> 单格半身。白龙娘抱臂侧过脸，表情故作淡然，却有一根手指悄悄点向旁边的小爱心；爱心刚亮起。只画白龙娘和这个简单动作，不画另一模型角色或社交软件界面。眼神稍微回望，表现她其实也觉得可爱。文字精确为“审美自由”。透明背景。

### F：先歇会吧

> 单格上半身。白龙娘把一只温热杯子轻轻推向画外，眼神认真温柔，嘴角放松，龙翼自然收拢。画外人物无需入镜。动作表达先照顾对方，不要得意或嘲弄。文字精确为“先歇会吧 今天先这样”，分成容易读的两行，字体清楚。透明背景，不加说教、诊断或第二句追问。

文字出错时的定向修正：保留原画面中的角色、动作与布局，只修正指定错误字，逐字复核全部台词；若文字区本身拥挤，提交主控决定短句或排版变更。避免把字体修复变成整套形象重做。

内置工具额度消耗与 API 美元报价是不同口径，不用上述单张价格推算订阅剩余张数。上游 adapter 的透明能力陈述与本地技能对 GPT Image 2 API 的说明存在差异；由于本轮没有选用 API，不据此承诺 API 透明输出，后续若选该路径再核对具体模型当时的官方契约。Nano Banana、Seedream 没有纳入拟用路线，本轮未核验其实时价格。
