# 血狼破军强度评价相关社区梗候选

检索日期：2026-10-14。优先采用 2025—2026 年本人投稿、本人动态和切片发布者页面；经典旧梗单列。

## 结论与证据边界

优先保留“超大杯 / Super Big Cup”“新神已至”“优势区间”“新时代大 C”四组；“拉个表看看”“兔头”有社区原帖的用法证据；“考考你呀”“全撤了”作为经典补充，当前证据较弱。

本轮实际读取的是搜索引擎收录的原站标题、简介、署名和日期。B站直接打开出现 HTTP 412；未完成音视频逐句听写，初次检索未取得 B站原评论楼层；后由主控补入一轮真实评论抽样，见第9—10项。“切片标题写了某句话”与“本人逐字说过某句话”分别标注。合集内推荐视频仅当作检索线索，未冒充当前视频正文。晋江讨论串的搜索摘要可见多段解释，但缺少楼层、用户名和绝对日期，因此不计为已核验的多个独立评论。

## 1. 超大杯 / Super Big Cup

- **含义与对象：** 用饮料杯型表达干员评价；“超大杯下、中、上”是进一步细分。英文喊法及其抑扬语调又被做成合集与二创。
- **观察：** 2025-06-02 的酒神切片标题给出“超大杯下-中”；2025-08-02 的遥切片同样采用该区间。2025-02-01 的二创标题直接使用 Super Big Cup，简介明确“仅供娱乐”。这证明评价格式及二创传播，未证明每个二创台词都是本人录音。
- **来源：** [酒神强度和技能组评价，2025-06-02](https://www.bilibili.com/video/BV1Jy7DzTET6/)；[遥强度评价，简介注明2025-08-02直播](https://www.bilibili.com/video/BV1pmh8zDESW/)；[Super Big Cup超大杯集团二创，2025-02-01](https://www.bilibili.com/video/BV1w4Ffe8EPT/)；[2025年Super Big Cup合集，检索摘要未显示绝对发布日期](https://www.bilibili.com/video/BV1GcB7BcEMm/)。
- **自然语境：** 群友贴新角色技能、问“这什么杯”，或看到夸张输出。
- **使用判断：** 优先采用；保留评级的模式条件，不从一句杯级推出所有玩家都应抽取。

## 2. 新神已至

- **含义与对象：** 用登神式夸张语气宣布极高评价，适合新角色表现带来明显冲击的场面。
- **观察：** 这是有本人投稿标题直接支持的表达：2026-02-15 的望测评、2026-08-07 的予愿安洁莉娜测评均使用它。本人 2024-04-25 动态也只有这一短句；该动态图片对象本轮未辨认，不据此指定角色。
- **来源：** [本人望测评，2026-02-15](https://www.bilibili.com/video/BV1wJZEBvEHM/)；[本人予愿安洁莉娜测评，2026-08-07](https://www.bilibili.com/video/BV1iCu46cEQR/)；[本人动态，2024-04-25 20:41](https://www.bilibili.com/opus/924322089343647766)；[讨论给望这一评价的切片，2026-02-15](https://www.bilibili.com/video/BV1RSZsBMEVc/)。
- **自然语境：** 强力新干员实装；旧难题被轻松解决；群友开玩笑给低星封神。
- **使用判断：** 优先采用；可归于血狼实际使用的测评表达，但不声称他创造了这个汉语短语。

## 3. 优势区间 / 找到了优势区间

- **含义与对象：** 正经用法是角色在某类地图、敌人和搭配下更合适；玩梗时则把很窄、很刁钻的胜利条件也叫“优势区间”。后者是依据语境作出的解释。
- **观察：** 2025-03-08 死芒切片标题把其优势区间描述为单路图；酒神评价合集多次围绕与其他干员的不同适用场景。2026-01-03 又有“银灰实装瓜分先锋优势”的切片标题，说明该表达可用于讨论角色位置变化。
- **来源：** [死芒评价，2025-03-08](https://www.bilibili.com/video/BV1RERpYhE31/)；[酒神评价合集入口，2025-06-02](https://www.bilibili.com/video/BV1Jy7DzTET6/)；[先锋优势变化切片，简介注明2026-01-03直播](https://www.bilibili.com/video/BV1QcijBWEAi/)。
- **自然语境：** 某冷门角色终于在特定关卡好用，或群友拿极端条件作比较。
- **使用判断：** 优先采用；它也是普通分析术语，是否在玩梗要看夸张程度，别见词就模仿主播。

## 4. 拉个表看看 / DPS多少，回转多少

- **含义与对象：** 把兴奋、厨力或外观评价突然切换成数值核算，形成强度党反差。DPS 指单位时间内造成的伤害；回转指技能再次可用的循环。
- **观察：** 晋江原讨论串的索引摘要直接以这组问句解释血狼相关“兔头”用法；另有 2025-09-04 切片把四人组合的理论伤害放到实战检验。后者支持“计算后还要实测”的工作方式，不等于这组问句的逐字出处。
- **来源：** [晋江原讨论串：段评里的兔头是什么意思，绝对发布日期未显示](https://bbs.jjwxc.net/showmsg.php?board=4&boardpagemsg=168&id=408394)；[祥子组合理论伤害与实战测试，简介注明2025-09-04直播](https://www.bilibili.com/video/BV15SatzvEDF/)。
- **自然语境：** 大家讨论立绘、皮肤或角色魅力时，有人突然问强度；或者几个人争论伤害数字。
- **使用判断：** 可采用为社区概括，不写成已核验的血狼固定逐字口头禅。该讨论串还需完整楼层记录才能声称多评论交叉验证。

## 5. 兔头 / 兔头发言

- **含义与对象：** 指向血狼的兔子头像及与之相关的强度讨论风格；也可以调侃把什么都拿来比较强度的发言。不能仅凭这两个字判定对方是其粉丝。
- **观察：** 同一晋江原讨论串将“兔头”与头像、按强度选角色、杯型评价相连。2023年的切片标题出现“若只兔头”，2025年的录播标题仍用“兔头”；这是跨年份使用痕迹，不是对辱称含义的背书。
- **来源：** [晋江原讨论串，日期待核验](https://bbs.jjwxc.net/showmsg.php?board=4&boardpagemsg=168&id=408394)；[“每个人进来就先发一句若只兔头”切片，检索显示约2023年，具体日期待核验](https://www.bilibili.com/video/BV1cN411v7yx/)；[空弦蕾缪安录播，简介注明2025-05-12直播](https://www.bilibili.com/video/BV1UK79zfEXg/)。
- **自然语境：** 熟悉社区的群友突然对日常事物也套杯级，或者自嘲“强度脑”。
- **使用判断：** 适合熟人自嘲和接对方主动开的梗；不把贬损变体自动带入常规聊天，不拿它评价用户智力。

## 6. 新时代大C / 新时代维什戴尔

- **含义与对象：** 用“新时代”强调输出能力或机制带来的代际落差；大C指承担主要输出的角色。“新时代维什戴尔”在此是对予愿安洁莉娜的切片评价用语。

- **来源：** [新时代维什戴尔切片，2026-08-01 13:40](https://www.bilibili.com/video/BV1LCG36dEPM/)；[予愿安洁莉娜总评，简介注明2026-08-01直播](https://www.bilibili.com/video/BV1gRG36EEY1/)。

- **使用判断：** 可采用，但只把它当有日期的评价话语。不给未核验的新角色自动冠以该称号，也不把旧角色一概说成失去用途。

- **含义与对象：** 用对称句调侃新角色上线后，有人得到配合、有人受到竞争；本例把酒神与伊内丝放在对比两端。
