# 工具改动交付流程

1. 拟定生成协议、参数输入和工具结果，明确调用者最终收到的内容。
2. 在已确认的接口上完成基础红绿测试。
3. 实际调用工具并输入参数，进行端到端测试，保存原始参数、返回结果、执行会话输入、真实轨迹与最终输出。
4. 将最终结果交由用户检阅，再按确认范围提交或部署。

检索任务协议由 begin_reading_task 根据 MCP 参数生成。日常检索、学习和测试使用相同的生成入口及轨迹字段；任务目标和必要上下文由参数区分。测试不以手工拼装的替代提示词证明线上效果。

验证每次使用独立时间戳目录；连续两轮核验目录独立、前次产物不变。真实模型测试按已确认预算运行，缺失证据保留缺失状态。
