## What to build

群成员明确要求搜索时，dot 实际检索公开资料，将简短回答和可核对来源发回原群。本任务不依赖跨事件记忆通过。

## 范围

检查该 dot 聊天实际搜索工具和审批方式，允许 QQ 通信工具与公开搜索；不开放私人资料、本机文件、账号操作或代码执行，不自动增加付费供应商。

## Acceptance criteria

- [x] 群内有界测试查询今日天气等高时效性公开信息，回答包含明确地点、日期和可访问来源；主控独立查阅同期来源，核对信息的时效性及一致性。以此验收当前公开信息查询效果，不以模型自述代替核对。
- [x] 搜索指令仅允许必要关键词，禁止提交无关群消息、成员昵称或整段群聊；实际查询参数有记录时核对，无记录时明确标记未独立核验。
- [x] 简短回答与来源相符，并发送到原测试群，用户确认实际收到。
- [x] 来源在 QQ 中可核对；若链接被平台拒绝，记录原因和所需设置，不静默删掉来源后报成功。
- [x] 搜索或审批异常明确报告直接阻塞，不改用未经确认的服务或模型猜测。
- [x] 搜索不改变订阅、接收群或群配置，离线发送边界回归通过。
- [x] 保存可取得的工具记录、QQ 展示结果、来源及核对时间、运行版本、命令、退出状态和回滚方法；平台工具轨迹缺失时如实记录，不写入凭据。
