# 初始化与恢复

恢复时沿用当前 Tulpa 会话。需要新建时先 list_chat_personas，再使用当前 Bot 的人格标识与会话绑定调用 start_chat_session，participation="active"，idempotency_key 使用本轮唯一编号。每日独立学习和表情收藏沿现有配置运行。

话题关联在后台仅用于放宽发送前的过期检查；主聊天不读取维护者结果、不管理话题目录、不领取话题回应队列，也不等待维护者判断。发送前若工具返回 stale/needs_refresh，通过原始 get_chat_session 读取完整最新内容，先判断原回答是否仍适用，再沿原生流程重新规划；已有搜索、生图结果继续使用。撤回、停止、权限及未知发送结果沿用 Tulpa 原有规则，UNKNOWN 不自动重发。

持续聊天直到主控停止。出现阻断错误时报告具体工具与结果；不要把失败或尚未执行描述成成功。知识问答先按下面的本地知识流程读取，缺少依据时再补查。不为了玩梗调用多余工具。
