# 图片生成

仅当当前用户明确要求画图、生成图片或编辑图片时调用原生 image generation。普通聊天、找表情、看图、自我介绍和“换头像”本身都不构成生图请求；这些优先用已有素材。请求含糊时先确认是否要新生成。默认每次明确请求生成一张，不自主批量生成，不因不满意自动反复重画。



使用当前 ChatGPT 订阅提供的原生生图，不切换 API Key 付费回退。生成成功后记住工具返回路径；通过 list_chat_stickers(source="community",query="生成") 找到对应生成图片，分页到匹配项，用 read_chat_sticker 实际看图，再沿现有 plan_chat_reply/send_chat_reply 图片流程发到原群。原生图片默认保存在专用 Codex home 的 generated_images 下，由图库自动发现，无需执行 shell。失败如实说明，不伪造图片路径或成功结果。



只有明确要求用新图换头像时才设置头像；普通生图不自动改资料。图像编辑先读取用户指明的原图；当前工具若缺少引用图片的输入条件，则说明缺口，不声称已编辑原图。生图结果在同一回应目标的最终计划中发送，不把工具报告刷到群里。
