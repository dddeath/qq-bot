# 卫戍协议：盟约版规则与运营

## 适用范围
国服「卫戍协议：盟约」2026-03 下半期规则快照。官方当期公告列出的开放窗口为 03-14 至 04-25；这个历史窗口不证明 2026-10-12 正在开放。当前入口、复开或后续规则应查游戏内公告。[官方活动预告，2026-03-11](https://ak.hypergryph.com/news/9697)

## 模式定位与关键循环
这是将自动作战、干员构筑与资金运营结合的玩法：在休整阶段调整阵容与装备，再进入作战阶段。与普通关卡逐个手动下人开技能的节奏不同。PRTS 记录了资金、调度、冻结、装备和阶段结算等帮助规则。[卫戍协议规则整理](https://prts.wiki/w/卫戍协议)

官方2026-03-14更新确认：独立模拟的休整期与机变阶段不限时，可暂离并在24小时内返回；同盟模拟关闭补足四人选项后可以不足四人开局；独立与同盟模拟的协议解锁进度互通。所有四、五星及活动赠送六星无需调用、未持有也可使用。这些变化会直接影响旧攻略是否适用。[官方盟约更新公告](https://ak.hypergryph.com/news/5114)

## 构筑案例：盟约下半期的谢拉格寒冷体系
版本：国服2026-03-14更新后的盟约下半期。目标是用寒冷/冻结提供输出窗口，以谢拉格成员与相关装备形成持续伤害；下列是规则与社区构筑的归纳，不承诺固定来牌或包通。

**可用骨架**：角峰承担前排，灵知提供寒冷/冻结环节，初雪与其他谢拉格成员补齐体系，后期依据来牌加入圣聆初雪、锏等输出。TapTap玩家的下半期个人攻略也采用“前期角峰配坚守、借外援补输出，后期银灰/初雪/灵知配合谢拉格与不融冰”的过渡思路；原页显示修改于03/18。[玩家构筑原帖](https://www.taptap.cn/moment/782716580197830151)

**装备核心**：官方03-14公告规定，「耶拉冈德之泪」由谢拉格盟约干员携带时，对其攻击范围内寒冷或冻结敌人每秒造成按自身攻击力计算的法伤；同一干员再装备「谢拉格不融冰」可提升该比例。因此两件装备集中到能覆盖主交战区的谢拉格携带者，比把伤害件放在看不到怪的位置有效。[官方装备更新](https://ak.hypergryph.com/news/5114)

**从过渡到成型**：
1. 先保证角峰一侧能接住怪、外援能清理，保留能接上谢拉格的低阶牌；没有输出时不为了人数强撤正在工作的外援。
2. 找到灵知或能启动体系的关键牌后再替换过渡位；合成、调度等级及装备获取依当前牌池，不照搬上半期耶拉的取得节奏。
3. 寒冷/冻结区域与泪的携带者攻击范围重叠。前排太远、携带者朝向不对，会导致看似装备齐全却打不出持续伤害。
4. 泪、不融冰未齐时继续用实际能打的单位过关，不把“理想后期装备”当现有战力。资金在回合结算清零，不能套用存钱吃利息的运营。[模式帮助](https://prts.wiki/w/卫戍协议/帮助)

**成立与失效**：有持续控制、能覆盖敌群的装备携带者及可靠前排时，体系才能形成控伤循环；敌人免疫相应控制、装备迟迟不到、前排先崩或双方范围脱节时，优先补直接输出/防线。联机先告知自己在等核心装备或来牌，别让队友把尚未成型的阵容当成能兜底的一路。

## 常见问答
**“必须四个人一起吗？”** 在上述盟约更新规则下，同盟模拟可以不补满四人；也有独立模拟。先确认所玩版本，再说房间设置。

**“我没这个四星是不是没法抄？”** 该版官方放宽了预设调用；先检查模式里的可用名单，不只看账号常规干员仓库。

**“2024那套攻略能照搬吗？”** 可参考运营思路，具体策略、牌池和装备要对照盟约版。比如自在道爷2024攻略是当时的核心协议方案，属于旧版参考。[创作者原帖](https://www.bilibili.com/video/BV1HoSuY8Ed6/)

**“资金是不是出过问题？”** 官方确认2026-03-27的终极模拟第4至8回合休整资金异常，于当日19:40修复，新开模拟应用修复。不能把那次异常写成现行规则。[官方修复说明](https://ak.hypergryph.com/news/9695)
