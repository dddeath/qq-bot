# 边狱巴士入门、队伍养成与战斗诊断

## 适用范围与剧透
基础系统与不依赖固定赛季的决策思路，无章节结局剧透。资料核验于 2026-10-12；不以本页作为当前卡池、最新人格、升级上限或活动排期的实时表。

## 人格、E.G.O 与配队
官方将人格描述为从其他可能世界借用的身份，E.G.O 则提供不同形式的强力手段；同一罪人可因配置不同而承担不同职责。配队应比较你实际持有的具体人格和可用技能，而不是只问某个罪人名字“强不强”。[官方系统介绍](https://limbuscompany.com/)

队伍建议从眼前关卡出发：需要可靠拼点、特定抗性、恢复还是某种状态积累？先补明显短板，再追求完整体系。仅因一个人格稀有或某张榜排得高，就把资源从已能运转的队伍抽走，可能延缓当前进度。

## 拼点和输出分开看
双方技能发生对抗时，强度与随机结果影响胜负；官方介绍强调利用技能组合、敌方弱点和效果调整队伍。[官方战斗介绍](https://store.steampowered.com/app/1973530/Limbus_Company/)

检查顺序建议：
1. 确认敌方最危险技能和命中后的效果。
2. 看自己的实际可用技能与当前状态，不只看角色养成总量。
3. 决定谁承接危险攻击、谁承担输出，留意技能条件有没有满足。
4. 行动后比较失败发生在拼点、伤害不足还是资源接续。

## 精神、硬币与拼点的基本算式
通常精神范围为 -45 至 +45，单枚硬币正面概率为 `(50 + 当前精神)%`：0 精神是 50%，+45 是 95%，不是必出正面。特殊被动与状态可能改写概率。加算硬币正面提高威力，减算硬币正面降低威力，因此负币技能要结合其专属精神机制判断。[社区战斗规则：精神与硬币](https://limbuscompany.wiki.gg/wiki/Battles)

普通拼点中，双方用剩余硬币计算威力，较低的一方损失一枚硬币，再继续拼；平点重掷，直到一方普通硬币耗尽，胜方用剩余硬币攻击。红色不破坏硬币有例外：输掉拼点后仍可能发动攻击，不能把“赢拼点”当成不受伤保证。[社区战斗规则：拼点及特殊硬币](https://limbuscompany.wiki.gg/wiki/Clash)

**短例**：一个基础威力 4、两枚 +3 硬币的普通技能，没有其他修正时，全反为 4，一正为 7，全正为 10；+45 精神只让每枚更容易正面，没有把范围直接变成固定 10。若拼点失去一枚，下一次只剩一枚可用于加点。看起来同一技能突然拼不过，先查剩余硬币、精神、等级修正与触发条件。

## 养成先看哪里卡住
| 当前问题 | 优先核对 |
|---|---|
| 大多数拼点都不利 | 等级与技能解锁／强化、状态、敌方被动 |
| 打得赢但续航差 | 恢复手段、抗性、承伤分配和资源安排 |
| 体系效果叠不起来 | 是否缺施加次数、关键组件或触发条件 |
| E.G.O 想用却不可用 | 是否装备、当场资源与使用条件 |
| 同一攻略跟着打也不行 | 版本、人格全名、强化阶段、模式与事件条件 |

这是排查顺序，不是当前版本的养成排行榜。询问具体兑换时，需要已有阵容、当前目标和可兑换页面；旧赛季“必换”名单不直接沿用。

## 镜之迷宫与限时内容
社区常把镜之迷宫称作“镜牢”，重复游玩叫“刷牢／打牢”。它的队伍构筑还受到 E.G.O 饰品和当局选择影响，所以镜牢顺畅不自动证明同一阵容适合所有主线或高难战。中文讨论中的奖励数量、刷新周期与可兑换范围应回到当期游戏说明核对。[中文玩家具体讨论样本](https://tieba.baidu.com/p/9514560992)

查询变更优先使用[开发团队 Steam 公告入口](https://steamcommunity.com/games/1973530/announcements/)，按发布日期找本次维护。不要用搜索结果里尚未到来的活动标题当成已实装。

## 问答例子
**“刚抽到强人格，要不要全资源给它？”** 先看它能不能直接改善你正在打的关卡，以及是否依赖尚未拥有的组件。能填现有短板的投入通常比同时开多个半成品体系更有效；这是养成建议，不是固定角色推荐。

**“镜牢里很强，主线怎么不行？”** 先剥离镜牢饰品与事件加成，再看本体技能和敌方机制。两种模式的构筑条件不同。
