# 心灵终结术语与问答

## 适用范围
适用于 3.3.6 的入门交流。以下通用对战词是解释性归纳；未把地方群昵称当成官方名称。涉及具体数值和免疫时查[机制文档](mechanics.md)。

## 常见称呼
| 称呼 | 在本库中的含义 | 回答时关注点 |
|---|---|---|
| MO、心终 | Mental Omega／心灵终结 | 先辨版本；不同魔改包可能沿用名称 |
| MCV、基地车 | 可部署成建造场的机动建设车 | 保护、扩张、是否允许重新部署 |
| 拉扯、风筝 | 边调整距离边输出，争取有效攻击窗口 | 速度、射程、地形和攻击方式 |
| 集火 | 多个单位集中攻击同一重要目标 | 是否过量伤害、是否因此暴露位置 |
| 断矿 | 采矿收入被骚扰、枯竭或路径问题中断 | 原因不同，补矿车未必解决问题 |
| 运营 | 资源、产能、科技、扩张和补兵的协调 | 不等同只造矿车或只攒钱 |
| 科技空窗 | 投入升级但新单位尚未到位的时间 | 对手能否在这段时间进攻 |
| 坦克海 | 大量坦克组成主力的通俗说法 | 仍要防空、反步兵、反控制和侦测 |
| 偷家 | 绕过主力攻击后方关键设施 | 需比较己方正面能撑多久 |
| 兵种克制 | 武器、目标类型、射程、免疫与成本的相对关系 | 不是只看单挑，也不等于绝对无伤 |

MCV 的模组机制可见[官方盟军单位页](https://mentalomega.com/ch/index.php?page=allied_units)。阵营正式名称可见[官方阵营页](https://mentalomega.com/ch/index.php?page=factions)。

## 群聊式问答
**“我怎么一波就没了？”** 先看这波是哪种损失：没带防空、反步兵不足、被控制、扎堆吃范围伤害，还是进入狭窄地形没展开。告诉我你和对方的主要单位，能比只看总数量判断得更准。

**“为什么三本造出来还打不过？”** 科技只解锁选项。若经济或兵力投入被科技建筑占用，新单位还没形成数量，反而会出现空窗。先看这项科技是否真的针对敌方阵容。

**“全是矿车我心控一个就赚？”** 先查矿车型号。至少官方盟军超时空采矿车明确免疫心控，不能按“昂贵就值得控制”的逻辑直接行动。[盟军单位页](https://mentalomega.com/ch/index.php?page=allied_units)

**“能不能给个万能开局？”** 可以给练习顺序，但固定建筑序列需要地图、资金、子阵营和对手条件。先做到收入持续、生产不停、侦察能发现第一波威胁，再优化建造秒数。

**“战役某英雄特别强，对战是不是无敌？”** 战役给定兵力、脚本、科技与胜利目标会改变单位价值。先核对多人模式是否可生产该单位，以及当局资源、数量限制和反制手段。[官方任务说明](https://mentalomega.com/ch/index.php?page=campaign)

**“网上说某阵营废物／无脑强，怎么判断？”** 让结论落到具体版本、地图、配兵和交战条件。能复现的同条件测试或完整对局比一个剪辑结果更有说服力。此库没有收录未经核验的当前天梯排名。

## 资料缺口
尚未收录完整逐单位数值、全部任务逐关攻略、现版本高水平赛事统计与社区特殊绰号。遇到这类细问，使用正式单位／任务名查对应官方页面或原始对局，不补造战术数据与“公认”结论。
